隐私Privacy

你的活动留在你的电脑上Your events stay on your computer

Stagio 完全在你的电脑上运行：不需要账号，不上云端，没有统计或追踪；除非你自己打开“有新版本时告诉我”，否则不会检查更新。除非你自己把文件发出去，关于你的活动的任何资料都不会离开这台电脑。Stagio runs entirely on your computer: no account, no cloud, no analytics or tracking, and it checks for updates only if you turn that on. Nothing about your events leaves the computer unless you send it yourself.

在你的网络上传送的What travels on your network

  • 手机、平板和讲台提示屏通过本地 Wi-Fi 连到电脑：投影片图片、备注、计时，以及那台设备自己的钥匙。连线是没有加密的 HTTP，同一个网络上的人有可能看到。请用你信任的网络，或者用 Stagio Wi-Fi（Windows，有自己的密码）。Phones, tablets and stage displays talk to the computer over the local Wi-Fi: slide pictures, notes, timers, and that device's own key. The connection is plain HTTP, not encrypted: someone on the same network could see it. Use a network you trust, or Stagio Wi-Fi (Windows; it has its own password).
  • 蓝牙遥控通过蓝牙传送指令，每个指令都带 PIN。The Bluetooth remote sends its commands over Bluetooth, each with the PIN.

会连到互联网的What reaches the internet

  • Stagio 程序本身：不会，它不连任何网上服务。唯一的例外是你在 Settings → About 自己打开 Tell me when a new version is out（默认关闭）：之后它每天一次，从 GitHub 上的下载发布页读取一个很小的文件 versions.json（只有版本号）。除了这个请求本身，不送出任何东西；GitHub 会看到这台电脑的互联网地址，和浏览任何网站一样。它从不自己安装任何东西。The Stagio app: nothing; it talks to no online service. The one exception is if you turn on Tell me when a new version is out in Settings → About (off by default): then, once a day, it reads one small file, versions.json (version numbers only), from the download release on GitHub. Nothing is sent but the request itself; GitHub sees this computer's internet address, as with any website. It never installs anything by itself.
  • 蓝牙遥控的网页，第一次是手机从 GitHub Pages 打开的，之后可以离线使用。The Bluetooth remote page is opened by the phone from GitHub Pages the first time; after that it works offline.
  • 这个网站、使用说明和下载文件由 GitHub 提供，GitHub 可能保存访问记录（见 GitHub 的隐私声明）。这个网站本身不用 Cookie，也没有统计；它只在你的浏览器里记住你选的语言和 Windows / Mac。This site, the guide and the downloads are served by GitHub, which may keep access logs (see GitHub's privacy statement). The site itself sets no cookies and has no analytics; it only remembers your language and Windows / Mac choice in your browser.

诊断资料Diagnostics

只有在你按 Settings → About → Save diagnostics 时才会产生，存成你电脑上的一个文本文件，直到你自己把它发出去。PIN、钥匙、配对码、Wi-Fi 密码和你的用户名都已去掉；发送前请先看一遍。Only made when you press Settings → About → Save diagnostics: a text file on your computer, until you send it yourself. The PIN, keys, pairing codes, the Wi-Fi password and your user name are taken out; read it before you send it.
