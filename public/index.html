    Stagio Wi-FiiPhone and Android

    This PC opens a Wi-Fi network for the phones. Works with no Wi-Fi at the venue, or when the venue Wi-Fi keeps phones apart from the PC. When this PC has internet it is Windows' Mobile hotspot, with the name and password set in Windows, and phones on it have internet too. Without internet it is a small network of Stagio's own, and phones on it have no internet.

    • Without internet: if the phone says the network has no internet, choose to stay connected.
    • If the phone joins but the page doesn't open: Windows may be blocking Stagio on this kind of network. Allow Stagio for public networks in Windows Security → Firewall → Allow an app.
    • It stays on while Stagio runs (Stagio starts it again if Windows turns it off); the name and password stay the same, so phones join again by themselves. Stop turns the Mobile hotspot off only if Stagio turned it on.
    Phone hotspotiPhone and Android

    A Mac can't open a Wi-Fi network of its own, but it can join the phone's:

    1. On the phone, turn on Personal Hotspot (iPhone) or Hotspot (Android).
    2. On this Mac, choose that phone's network in the Wi-Fi menu.
    3. Close this window and click Remote again: the code above then points at this Mac on the phone's network. Scan it with that same phone.
    BluetoothAndroid phones, in Chrome

    For when no Wi-Fi works at all. The phone controls slides, black/white, cues and fades; it shows the slide number, not pictures. iPhones can't use Bluetooth from a web page: use Stagio Wi-Fi.

    PIN
    • The code opens the page and gives the phone a key: nothing to type. Opened another way (home screen, typed address): type this PIN, the one at the top of this window, not the Stage PIN. Scanning is safer: commands signed with the PIN could be guessed by someone who recorded them.
    • Tap Connect and choose this computer in the list (only computers running Stagio Bluetooth appear there).
    • The first time the page needs internet (mobile data is fine); after that it works offline. Add it to the home screen.
    Install on the phone's home screen
    • iPhone / iPad (Safari): open the link, tap Share, then Add to Home Screen.
    • Android (Chrome): open the link, tap ⋮, then Add to Home screen.
    • Mac (Safari): open the link, then File → Add to Dock.
    • The icon opens Stagio full screen. The first time, enter the PIN once.
    • The icon remembers this PC's address. If it stops connecting, the PC's address has probably changed: scan the new code and add it again. Reserving the address in the Wi-Fi router stops this from happening.
    Phone can't connect?
    • The phone must use the same Wi-Fi, not mobile data or a guest network. Some routers block devices from seeing each other (“AP isolation”); turn that off or use another network.
    • Keep Stagio running on this PC.
    • The first time Stagio runs, Windows asks whether to allow it on the network: choose Allow, for both private and public networks.
    • If the page never loads, security software on this PC may be blocking port 7300. Allow Stagio / port 7300 there.
    • QR scanners inside chat apps sometimes fail; open the link in the phone's normal browser, or type the address and use the PIN.

    New versions

    Off unless you turn it on. Then Stagio asks the download site (on GitHub) once a day which version is the newest, and says so here when there is a newer one. Nothing about you or your events is sent; GitHub sees this computer's internet address, as with any website. Stagio never installs anything by itself.

    When something goes wrong

    Saves a text file to send with a problem report: the version, this computer's system, how Stagio's helpers are doing, and the end of Stagio's log. The PIN, the keys, pairing codes, the Wi-Fi password and your Windows or Mac user name are taken out. Read it before you send it.

    Mac check

    Collects what PowerPoint and macOS allow on this Mac, so the Mac-only parts can be finished. Run it once with a presentation open and once during a slide show, then copy the text and send it. It only reads; it changes nothing. (It includes the names of the open presentations.)

    Microphone: gain, EQ, noise gate

    Low cut takes out rumble and handling noise; a little Mid around 3 kHz makes speech clearer. The gate closes the microphone between words, so the room noise isn't amplified.

    Opening countdown

    Full screen on the projector until the event starts. With one screen it opens in a window on this one.

    Before the event

    What Stagio can check from here. Amber or red needs a look.

    Not checked: what the projector and the speakers really show and play. Look at the screen and play a few seconds of music before people arrive.

    Cues

    Steps run top to bottom. Fades run in the background, so the next step starts right away.

    A cue can also run by itself when the show reaches a slide going forward (not when stepping back). It stays with that slide if slides are added or moved. Whoever builds the slides can do the same by writing [cue: name] in a slide's notes.

    Run of show

    The parts of the event, in order. Next part does what each part needs: opens the speaker's file and starts its slide show, shows the countdown on the projector, brings the music in. The next file is opened ahead of time, so the change is quick. Planned minutes tell you how far ahead or behind you are.
